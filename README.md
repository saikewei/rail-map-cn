# 全国客运铁路运营图

一个可离线打开的中国国家铁路客运线路交互地图。单文件 HTML，无外部依赖、无需 API Key。

**在线预览：** <https://saikewei.github.io/rail-map-cn/>  
**交互地图：** <https://saikewei.github.io/rail-map-cn/map.html>  
**GitHub：** <https://github.com/saikewei/rail-map-cn>

**打开方式：** 访问 GitHub Pages 首页后点击「打开交互地图」，或直接打开 `map.html`。也可下载 `全国客运铁路地图.html` 后在浏览器打开；已在 Chrome / Edge 中测试通过 `file://` 直接打开。

---

## 内容

- **432 条**具备图定旅客列车业务的具名线路（按本图口径），以线路最高运营速度着色：350 / 300 / 250 / 200 / 160 / 140 / 120 / 80 km/h。
- **3,300 座**办理客运业务的车站，全部落图；按图定停靠频次分成四级显示，缩放后逐级展开。
- **枢纽交汇优化**：所有由不同线路交汇的办客站，统一用短连接线与节点衔接，避免线路在站端“断开”或彼此不相接；不再绘制逐条到发线，避免把地铁/站场线误当成干线。
- **自然水系重绘**：河流、湖泊升级为 Natural Earth 1:10m 数据；长江、黄河、珠江、黑龙江、雅鲁藏布江等主要河系加粗并标注中文名。
- **线路档案显示全部办客站**：选中线路后，按图定经行顺序列出该线所有 12306 办客站，可滚动查看并逐站打开档案。
- **精确的国界、省界与海岸线**：采用天地图国家标准矢量地图 2025 版（审图号 **GS(2024)0650**），不再使用低分辨率近似轮廓；含台湾岛、海南岛、南海诸岛与十段线。
- **省 / 地 / 县三级行政地名**：34 个省级、333 个地级、2,869 个县级标注；省级与地级默认开启，县级默认关闭，可在面板中逐级开关；省界亦可单独隐藏。
- 线路名称与运营时速直接标注在地图上；标签自动避让，并随缩放选择合适的位置。
- 点击线路或车站可查看档案：
  - 线路：速度等级、线路类型、关联车站/城市、主要车站、技术备注。
  - 车站：所属地区、电报码、拼音简拼、经纬度、图定停靠频次、接驳客运线路。
- 全部线路目录可搜索、可按高速/普速筛选；全局搜索支持线路名、车站名、拼音与电报码。
- 昼夜单主题纸本风格；含南海诸岛、十段线、比例尺、指北针与地图注记。

## 数据来源与口径

| 数据 | 来源 | 快照/说明 |
|---|---|---|
| 铁路线位与站场几何 | [OpenStreetMap](https://www.openstreetmap.org/) | 2026-09-24 快照，ODbL 许可；经拓扑合并、简化 |
| 车站、电报码、图定列车 | [中国铁路 12306](https://www.12306.cn/) | 2026-10-18 快照；图定列车经停与停靠频次 |
| 国铁网规模 | [国家铁路局《2024年铁道统计公报》](https://www.nra.gov.cn/xwzx/xwxx/xwlb/202506/t20250606_348989.shtml) | 2024 年末：16.2 万公里，其中高铁 4.8 万公里 |
| 最新全国规模 | [人民日报海外版（2026-01-05）](http://paper.people.com.cn/rmrbhwb/pad/content/202601/05/content_30129239.html) | 2025 年末：16.5 万公里，其中高铁 5.04 万公里 |
| 国界、省界、海岸线、南海诸岛 | [天地图国家标准矢量地图](https://geojson.cn/data/atlas/tiandi) | 审图号 GS(2024)0650，2025 版；含台湾岛、海南岛、南海诸岛及十段线；仅作亚百米级抽稀 |
| 省 / 地 / 县行政地名 | [阿里云 DataV.GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector) | 34 / 333 / 2,869 个行政中心点 |
| 周边陆地、河流湖泊 | [Natural Earth](https://www.naturalearthdata.com/) | 周边陆地、河流、湖泊均为 1:10m；主要河流按等级加粗并加中文标注 |
| 主要江河水面 | OpenStreetMap / OpenFreeMap z9–z11 water polygons | 补足长江、黄河、钱塘江、珠江等宽河段/三角洲的水面轮廓；ODbL |
| 枢纽连接 | OpenStreetMap / 12306 | 按车站关联合并线位，短连接线为制图综合，不代表实际道岔位置 |

线路速度按线路**最高运营速度等级**标注。主要干线依据国铁集团/国家铁路局公开技术标准和现行图定运行时分交叉核对；同一线路不同区段限速或低等级运行时，按全线最高等级标注，并在备注中说明。部分支线按线路等级归纳，不代表全线各区段实际运行速度。

国界、省界与海岸线来自带审图号的国家标准矢量数据，处理时仅做亚百米级坐标抽稀，不重绘或近似替换边界。行政地名按行政等级设置显示比例尺：省级在总览显示，地级在省级轮廓之上展开，县级需要在面板中开启并在放大后显示。省级名称在更大比例尺下让位于地级/县级标注，以避免地名堆叠。

车站—线路关联依据图定列车在站场咽喉区的邻接轨道与线路邻近度计算，用于空间表达，不等同于官方车站业务台账。线路档案中的沿线车站只保留 12306 办客站，并按图定列车经行顺序排列；线路相交的枢纽可能同时列出多条线路，属正常现象。

此前有短联络线出现断口（如上海南站附近的沪春铁路）。原因是几何筛选只保留了有图定客流的路段，零客流但仍属同一条线的连续区段被裁掉。现在改为**按线路名合并全部 OSM 线位（含零客流段）**，并对同线残端做不超过 300 m 的桥接；不同线路经过同一办客站时，再用短连接线和节点连接。连接线只用于制图清晰，不等同于实际道岔或站场布置。

补入的 **三乐旅游铁路**（三亚—崖州，200 km/h，2024-11-16 开通）和 **金温铁路老线**（即金温货线，仍有少量普速办客列车，按 80 km/h 级标注）来自 12306 图定经行与 OSM 线位；三乐旅游铁路是海南老西环线目前办理客运的区段。老西环其余区段仍以货运为主，不按客运线路绘制。

## 范围说明

- 绘制对象为中国国家铁路网中办理旅客列车业务的线路，包括高速客运专线、城际铁路和承担客运的客货共线铁路。
- 不绘制城市轨道交通（地铁、轻轨、有轨电车）和地方铁路；运行图中未开行旅客列车的货运线、联络线、疏解线、动车走行线等不单独作为客运线路呈现。
- 不含台湾地区铁路（不在本图 12306/OSM 数据范围），但底图完整包含台湾岛。
- 补入三乐旅游铁路与金温铁路老线；海南老西环其余货运区段不纳入客运线路。
- 广深港高铁香港段属国家高铁通道，图中保留；香港段由港铁公司运营，最高运营速度 200 km/h。
- 数据与边界仅用于学习、研究与展示，不作为国界、测绘、工程设计或出行依据。行政边界采用带审图号数据，但本图并非正式出版地图。

## 文件

- `index.html` — 轻量 SEO 落地页与 GitHub Pages 入口，便于搜索引擎收录。
- `map.html` — 最终单文件交互地图；`全国客运铁路地图.html` 为同一文件的本地副本。
- `preview/` — 桌面总览、西藏边界、长江口、钱塘江、珠江口、黄河、自然水系、沪春铁路/上海南枢纽、线路详情、车站详情、移动端总览。
- `data/admin/` — 边界与行政地名原始数据；`scripts/build_admin_basemap.py` 生成精确行政底图。
- `src/`、`scripts/`、`data/` — 数据处理、样式和构建脚本。

## 重建

```bash
python3 scripts/build_admin_basemap.py   # 精确行政底图（需 Shapely，仓库内 .pydeps 已提供）
python3 scripts/build_china_land.py      # 省界与 Natural Earth 1:10m 陆地求交，形成统一陆地蒙版
python3 scripts/build_nation_land_borders.py  # 仅保留陆上国界，删除海岸线描边
python3 scripts/build_prov_land_lines.py      # 仅保留陆上省界，删除沿海省界描边
python3 scripts/build_water.py           # Natural Earth 1:10m 河流、湖泊与主要水系标注
python3 scripts/fetch_lower_yangtze.py   # OSM 长江下游水面（补足 NE 中心线缺口）
python3 scripts/fetch_major_water.py     # OSM 长江口、钱塘江、黄河、珠江等宽河段水面
python3 scripts/build_data.py            # 铁路、车站、标签数据
python3 scripts/enrich_line_data.py      # 补入三乐/金温老线，补全沿线办客站顺序
python3 scripts/repair_line_geometry.py  # 合并同线全部 OSM 线位，修复断口并生成枢纽连接
python3 scripts/build.py                 # 打包为单文件 HTML
```

`build_admin_basemap.py` 读取 `data/admin/100000.json`（天地图标准矢量，GS(2024)0650）、`admin_labels.json` 与 Natural Earth 陆地数据，生成行政底图。`repair_line_geometry.py` 读取 OSM 原始网络，按线路名合并同线全部线位（含零客流段）并生成 `junctions.json`；若缺少 Shapely，可先 `python3 -m pip install --target .pydeps shapely`。
